FLOW STUDIO HELPER - WINDOWS 10/11 x64

1. Giải nén toàn bộ file ZIP.
2. Nhấp đúp Install-Flow-Studio-Helper.cmd.
3. Nếu Windows SmartScreen hiện cảnh báo: chọn More info > Run anyway.
4. Cài/mở Google Drive for desktop và đăng nhập tài khoản @ikameglobal.com được cấp quyền.
5. Chờ thư mục Shared drives / Bộ nhớ dùng chung xuất hiện trong Google Drive.
6. Quay lại Studio Web > Resize & Upload > Kiểm tra lại.

Helper được cài trong tài khoản Windows hiện tại, không cần quyền Administrator và tự chạy khi đăng nhập. Mỗi máy giữ hàng chờ và file resize riêng; project và video trên Studio Web vẫn dùng chung theo quyền tài khoản.
